# INPAY 代付订单凭证发送流程

用于商户索要 INPAY 代付订单凭证、付款凭证、transfer proof、payout receipt、成功截图等场景。

典型触发：

```text
KKB2607301807532377853828 给下凭证
```

关键要求：

- 必须先去后台查询对应代付订单。
- 必须回读订单真实字段。
- 只有订单存在、商户归属匹配、金额/账号/订单号匹配、且状态明确成功时，才引用商户原消息并发凭证。
- 非成功订单不发凭证，只回复/引用原消息说明当前后台状态。
- 发送的凭证必须引用触发订单号，例如显示在 `Out Trade No` 字段。
- 凭证截图样式要贴近后台详情卡片：白底、浅灰边框两列表格，标题 `Payout Transfer Details`，`Payout Success` 用绿色文字。
- 不得泄露后台内部信息、通道成本、备注、密钥、Token、Cookie 等。
